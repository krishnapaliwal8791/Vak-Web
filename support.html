Dictation doesn’t start

Check that Vāk is running, the configured hotkey is correct, and Windows allows microphone access for desktop apps.

Text doesn’t appear

Make sure the target application has focus and the cursor is in an editable field. Vāk inserts text through the clipboard and a paste action.

Transcription is slow

Speech recognition runs locally. Model size and available computer resources affect processing time.

Model download failed

Check your internet connection and available disk space, then retry the download from Vāk’s setup or settings screen.
